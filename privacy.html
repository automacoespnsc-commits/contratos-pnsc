1. Quais dados do Google acessamos

Com a autorização da conta Google responsável, a automação acessa apenas os arquivos da pasta de contratos indicada no Google Drive (para ler os PDFs novos) e a planilha de destino no Google Sheets (para gravar o resultado). Não acessamos e-mails, contatos, agenda ou outros arquivos.

2. Como usamos os dados

O conteúdo dos contratos é usado exclusivamente para identificar informações como partes, valores, datas e prazos e registrá-las na planilha. Para essa identificação, o texto extraído dos contratos é enviado à API do Google Gemini, que devolve os campos encontrados. Os dados não são usados para publicidade, perfilamento ou qualquer outra finalidade.

3. Compartilhamento

Não vendemos nem compartilhamos dados com terceiros, exceto o processamento descrito acima. O uso das informações obtidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado.

4. Armazenamento e segurança

Os dados ficam na conta Google da própria organização (Drive e Sheets) e no servidor de automação usado pela equipe, com acesso restrito às pessoas responsáveis.

5. Revogar o acesso e excluir dados

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions. Para solicitar a exclusão de dados, entre em contato pelo e-mail abaixo.
